MiniMe

A local AI assistant powered by Ollama, FastAPI and React.

Current Features
---------------
✅ Local LLM (Qwen3)
✅ Streaming responses
✅ Conversation memory
✅ Persistent chat history
✅ REST API using FastAPI
✅ React frontend
✅ Frontend ↔ Backend communication

Upcoming
---------

- Streaming in browser
- Multiple chat sessions
- RAG
- Voice assistant
